# Trabalho de Análise de Regressão — Grupo 4

## Requisitos

Para compilar o arquivo `main.qmd` em PDF, certifique-se de:

1. **R** versão min. `4.2`
2. **Quarto CLI**
3. **TinyTeX**
4. Arquivo `main.qmd` deve estar na mesma pasta do arquivo `casas.csv`
5. Ter os pactores listados no ínicio do arquivo `main.qmd` instalados.
